### ⚡  Executive Engineering Profile

* 🔭 **Current Position**: **Software Development Engineer II (SDE 2)** at **Dhan AI**, progressing from Junior Engineer → SDE 1 → SDE 2.

* ⚙️ **Core Backend Specialization**:

  * Designing and building **event-driven microservices** using **Node.js, TypeScript, Apache Kafka**, partitioned consumer pools, retry mechanisms, dead-letter queues (DLQ), and idempotent processing.
  * Engineering **high-performance data layers** with **PostgreSQL, MongoDB, TypeORM**, query optimization, indexing, transactions, connection pooling, and scalable data-access patterns.
  * Building **low-latency caching and distributed coordination layers** using **Redis**, including caching strategies, rate limiting, distributed locks, and session management.
  * Designing **production-grade APIs** using **REST, GraphQL, Apollo Server, and PostGraphile**, with emphasis on API contracts, validation, versioning, reliability, and maintainability.
  * Developing **scalable asynchronous processing systems** for background jobs, scheduled workloads, retries, event processing, and third-party integrations.
  * Building **fault-tolerant distributed systems** with graceful failure handling, retry strategies, idempotency, circuit-breaker patterns, observability, and recovery mechanisms.

* ☁️ **Production & Cloud Engineering**:

  * Containerizing backend services with **Docker** and deploying scalable workloads using **cloud infrastructure and container orchestration platforms**.
  * Designing production deployments with **load balancing, horizontal scaling, health checks, rolling deployments, canary releases, and zero-downtime deployment strategies**.
  * Implementing **CI/CD pipelines** covering automated builds, testing, security checks, artifact management, staging, and production releases.
  * Working with **Microsoft Azure** services including secure secret management, application infrastructure, monitoring, and cloud-native integrations.

* 🔐 **Reliability, Security & Observability**:

  * Implementing **authentication, authorization, RBAC, secure API communication, secrets management, and encryption** for production systems.
  * Building observability into backend services through **structured logging, metrics, distributed tracing, request correlation, dashboards, and alerting**.
  * Designing systems around **high availability, fault tolerance, data consistency, scalability, and operational resilience**.

* 🧠 **Engineering Focus**:

  * Strong focus on **backend architecture, distributed systems, API design, databases, event-driven architecture, system scalability, production deployments, and performance optimization**.
  * Experienced in taking backend services from **design → development → testing → deployment → monitoring → production support**.
  * Comfortable working across the full backend lifecycle while maintaining a strong focus on **clean architecture, maintainability, reliability, and scalable engineering practices**.
